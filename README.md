# LSC Agent — Rep Visit IA Exploration

Working folder for the Life Sciences Cloud (LSC) Rep Visit iPad app IA/navigation prototype.

## Files

- **`index.html`** — clickable HTML wireframe (open directly in a browser). Six iPad screens: Today, Accounts, HCP, Visits, Visit, In-Visit. 1194×834 landscape frames.
- **`research-findings.md`** — synthesized user-research findings informing the design.
- **`design-decisions.md`** — what the current wireframe does and why, mapped to research signals.

## How to use

```sh
open "/Users/vocampo/LSC Agent/index.html"
```

Click top tabs to switch screens. Toggle **1:1 ↔ Group** on the Visit record and In-Visit modal to compare SPA variants.

## Current version

**v2 — research-informed** (Oct 7, 2026). Applies: All-Actions SPA · no tabs on records · voice-first · Next Best Actions · Past Context promoted · side-panel attendee navigator for group visits.
